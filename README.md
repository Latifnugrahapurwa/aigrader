# AI Grader Sistem

Aplikasi web untuk mengoreksi Lembar Jawaban Komputer (LJK) otomatis dengan Gemini Vision. Berjalan sepenuhnya di browser (tanpa backend).

## Menjalankan di komputer

    npm install
    npm run dev

## Build untuk hosting

    npm run build

Hasil build ada di folder `dist`. Di Vercel atau Netlify: Build command `npm run build`, Output directory `dist`.
